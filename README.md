# Comunidad — Laboratorio de Git & GitHub

Este repositorio **no es el código del laboratorio**. Es el **buzón**: acá quedan los comentarios y las sugerencias de mejora.

El laboratorio (la app) vive en otro repo, **privado**. Giscus, en la página Comunidad de la app, escribe acá, en [Discussions](https://github.com/AAGG22/laboratorio-git-github-comunidad/discussions).

## Cómo sugerir

1. Entrá a la app → menú **Comunidad**.
2. Comentá con tu cuenta de GitHub (la misma que usás para aprender Git).
3. O abrí una Discussion en este repo, categoría **Sugerencias**.

Al comentar, tu mensaje es **público** en este repositorio. El texto sigue siendo tuyo; GitHub lo muestra acá.

## Qué no va acá

- El código de la app.
- Secretos, contraseñas o datos personales.
- Issues de un repo que no es este: el código se corrige en el laboratorio privado.
